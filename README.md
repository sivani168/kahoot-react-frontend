# Quizly React Frontend

A React + Vite frontend recreated from the supplied mobile screenshots.

## Features
- Responsive purple navigation bar
- Hero section
- Create / Host / Play / Learn sections
- Functional game PIN join form
- Functional celebration carousel
- Expandable FAQ
- Expandable mobile navigation
- Sticky premium-style promotional bar
- Responsive footer

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

The project is frontend-only. Buttons and links are demo interactions and can be connected to a backend/API later.
